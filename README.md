# 🛋️ Интернет-магазин мебели «Интерьер»

Адаптивная верстка многостраничного веб-сайта для мебельного магазина, выполненная строго по графическому макету. Проект включает в себя детальную проработку трех ключевых страниц, интерфейсных состояний и анимаций.

---

## 🎯 Цель проекта
Демонстрация навыков качественной, современной верстки и точной реализации многостраничного дизайнерского макета (Pixel Perfect). Проект показывает умение работать со сложными сетками товаров, динамическими UI-элементами и адаптивными интерфейсами без использования сторонних фреймворков.

## 📄 Структура сайта (Многостраничность)
Проект состоит из 3 полноценных страниц с настроенной навигацией между ними:
1. **Главная страница:** Презентация магазина, баннеры, промо-блоки и навигация.
2. **Каталог:** Сложная сетка карточек товаров с элементами фильтрации и сортировки.
3. **Корзина:** Интерфейс оформления заказа, список выбранных товаров, таблицы и формы.

## ✨ Ключевые особенности и UI-анимации
* **Pixel Perfect:** Максимально точное соответствие исходному дизайн-макету (отступы, шрифты, размеры элементов).
* **Интерактивные карточки товаров:** При наведении (hover) на карточку в каталоге на ней плавно появляются иконки «Добавить в избранное» и «В корзину» (интерфейсные заглушки, готовые к интеграции с JS).
* **Анимация кнопки заказа:** Элементы призыва к действию (CTA), включая кнопку оформления заказа, снабжены плавными CSS-эффектами при наведении.
* **100% Адаптивность:** Сайт корректно перестраивается и отлично отображается на любых устройствах — от мобильных телефонов до широкоформатных мониторов.

## 🛠️ Стек технологий
* **HTML5:** Семантическая разметка (использование `header`, `nav`, `main`, `section`, `footer` и др.) для хорошей читаемости кода и SEO.
* **CSS3:** 
  * Современные модули раскладки (**Flexbox** и **CSS Grid**) для построения адаптивной сетки каталога и структуры страниц.
  * Кастомные свойства (CSS-переменные) для удобного управления палитрой цветов.
  * Эффекты `transition` и `opacity` для реализации плавного появления иконок и анимации кнопок.
  * Медиа-запросы (`@media`) для адаптации под мобильные экраны.

## 💻 Локальный запуск и просмотр
Проект выполнен на чистом стеке и не требует установки дополнительных зависимостей или серверов. Вы можете запустить его локально на своем компьютере:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/yademon220/site-Interior/
   ```
2. Откройте папку с проектом.
3. Просто запустите файл **`index.html`** в любом удобном браузере, чтобы посмотреть главную страницу.
